I'm a first-year Computer Science student at NUS who'd rather build the thing than read about it.

Somewhere between a 3am debugging session and a lecture on discrete maths, I found the part of computing I actually love: taking an idea that only exists in my head and forcing it to run on real hardware, for real people. Systems, interfaces, algorithms — whatever the problem needs.

Right now I'm deep in data structures, low-level C, and the kind of side projects that start as a joke at 1am and end up on GitHub by morning. I care about craft — code that's readable, products that feel considered, details nobody asked for.
